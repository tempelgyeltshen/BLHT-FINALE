# Bhutan Land of Happiness and Tours
A website for tourists to learn about Bhutan and also our company and what services we provide

This repository is organized as two applications:

- `frontend/` — the Vite and React website.
- `backend/` — the Express API.

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

Run the API separately with `cd backend && npm install && npm run dev`.
